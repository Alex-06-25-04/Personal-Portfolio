# My Portfolio

Portfolio personale realizzato con React + TypeScript e Vite. Questo repository contiene il codice di una semplice applicazione single-page pensata per mostrare progetti, informazioni personali e contatti. Il tono del progetto è professionale ma adatto a uno sviluppatore junior che vuole presentare il proprio lavoro.

**Stato:** Progetto di esempio / portfolio personale (work-in-progress)

## Caratteristiche

- Pagina hero con introduzione
- Sezione "About" con informazioni personali
- Sezione "Projects" per mostrare progetti con immagini e link
- Pagina "Contact" con form e dati di contatto
- Layout responsivo e componenti riutilizzabili

## Tecnologie

- React
- TypeScript
- Vite
- CSS (file `src/App.css` e `src/index.css`)

## Requisiti

- Node.js (>= 16 consigliato)
- npm o yarn

## Installazione

1. Clona il repository:

```
git clone <repository-url>
cd my-portfolio
```

2. Installa le dipendenze:

```
npm install
```

3. Avvia il server di sviluppo:

```
npm run dev
```

Apri il browser su `http://localhost:5173` (o sulla porta indicata dal terminale).

## Build e distribuzione

Per creare la build di produzione:

```
npm run build
```

Per testare la build localmente:

```
npm run preview
```
